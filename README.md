# Поезд за рассветом — Unity Android

Unity 6000.3.25f1 / URP 17.3.0. Исходники игры находятся в DawnrailSource.zip.
Архив содержит Assets, Packages, ProjectSettings и данные проверки исходной логики.
Перед импортом проекта облачная сборка запускает pre-build.sh для распаковки.
Pre-export method: Dawnrail.Editor.CloudBuild.PreExport
Тестовый Android пакет: net.nightcity.dawnrail.unitytest; ARM64; APK, не AAB.
Это разрабатываемый перенос на Unity; наличие исходников не подтверждает успешную сборку или проверку на телефоне.
